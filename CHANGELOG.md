# Changelog

## 0.1.0

Initial release.

- Context analysis pipeline for JavaScript/TypeScript/JSX/TSX built on the TypeScript compiler API
- 82 context-aware commands: core (Shift+F1–F12), control flow, imports/exports, React, backend, testing, refactoring
- Smart Action (Ctrl+Shift+Space) with relevance ranking
- Import merging, duplicate prevention, indentation/EOL preservation, style detection
- Status bar, settings, output channel, pluggable language adapter and AI provider interfaces
